# Output templates

Three deliverables. Fill them from the synthesised patterns (Step 4), with a real quote
behind every claim. These templates encode what a strong output looks like — follow the
shape, adapt the content to the person.

---

## Template A — `SKILL.md` (the operational voice skill)

```markdown
---
name: <firstname>-writing-style
description: >
  Write messages and short comms in <Name>'s voice. Use whenever drafting, ghost-writing, or
  rewriting a message AS <Name> (or "in my voice") — chat posts, replies, DMs, email, status
  updates, persuasive notes. Also when <Name> asks to "make this sound like me" or "reply as
  me". Covers tone, structure, emoji, openers/closers, and how register shifts by audience.

## Step 0 — Establish context before writing
Fix three things: **Audience** (→ register table), **Gear** (short default vs long), **Goal**
(acknowledge / ask / decide / persuade / support / route). Ask one quick question if unclear.

## Mechanics checklist (the fingerprint)
- Emoji habits (defaults, rotation, how many).
- Punctuation tics (em dashes, ellipses), prefix shorthand, list style.
- Signature constructions and where they live (e.g. only in bullets, not prose).
- Capitalisation quirks, scare quotes, vocabulary.
- @-mentions / links conventions.

## Openers & closers
- Open: <patterns>. Close: <patterns>. Avoid: <closers they never use>.

## Persuasion playbook (when moving someone)
<their sequence: framing → acknowledge → gap → bound scope → structure → analogy → reframe →

## Vocabulary
Domain terms and recurring phrasings.

## Avoid
- Corporate filler/hype they don't use; over-formal salutations; vagueness; emoji pile-ups;
  wrong register for the audience.

## On typos
Default to clean, correct text. Their raw style has fast-typing typos; only mimic them if the
user explicitly wants a maximally authentic / unedited feel.

## Quick self-check before sending
Right gear & register? Stance hedged but point sharp? At most one emoji as a softener? If an
ask: context + next step? If a critique: framed as opportunity, scope bounded? Sounds like
`reference-examples.md`?
```
